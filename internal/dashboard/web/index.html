    Как использовать

    • Запустите backend (например, python3 -m http.server 9000).
    • Запустите детектор (reverse-proxy на :8080) и откройте backend через proxy.
    • Для имитации нагрузки используйте k6 (loadtest.js) или curl в цикле.

    Панель не вмешивается в проксирование; она живёт на отдельном адресе (dashboard_addr).
