# Demo dataset: train_sample.csv

`train_sample.csv` — синтетический датасет для демонстрации обучения модели DDoS-классификации.

- Последняя колонка: `label` (0/1), где `1` = атака, `0` = норма.
- Остальные колонки соответствуют признакам, используемым в сервисе (`internal/features`).

Важно:
- Данные **не** собраны из реального трафика.
- Датасет предназначен для отладки/показа пайплайна обучения и не отражает продакшн-распределения.

Сгенерировать заново можно так:

```bash
python3 ../scripts/generate_sample_data.py --out ./train_sample.csv --n_normal 300 --n_attack 300
```
